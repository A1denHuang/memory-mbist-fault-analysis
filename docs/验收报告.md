## 结果边界

未覆盖项包含标准March未敏化的长保持故障、物理上不适用的耦合顺序交叉组合和部分未命中的故障元素组合。没有通过删除未覆盖bins制造100%覆盖率。

仅凭失效CSV，某些SAF、TF及耦合故障不可唯一辨识。首选分类的69.09%包含未检出的DRF样本；候选命中率不能作为唯一分类准确率。改进方案及全部错误样本保留在分析报告。

参考序列与存储状态独立，但 DUT 存储器与 reference_memory 共用 sram_fault_model 实现。scoreboard 验证控制器；故障语义由51项模型单元检查支撑，两者不是独立故障实现之间的互证。

新版分析同时提供仅合并 SAF0/TF_UP 后的指标，以及 toggle/rewrite 辅助测试结果。辅助测试增加操作成本，并依赖每个试验重新初始化行为模型。已审阅的55例列作开发集评估，新种子评估另列，见 `results/followup/report.md` 和 `results_followup/report.md`。

公开仓库：https://github.com/A1denHuang/memory-mbist-fault-analysis 。CI工作流在每次推送时运行，远程执行状态以 GitHub Actions 页面为准。没有执行工艺综合、STA或芯片级HBM验证，未声明面积、频率或硅后准确率。
